# DejaVu Sans (runtime copy)

Runtime WOFF faces for the optional **DejaVu Sans** interface font
(Settings → Appearance → Interface font). Byte-identical copies of the
approved package in `design-references/jenkin-branding/fonts/` (DejaVu 2.37,
full WOFF, no subsetting): Regular 400, Bold 700, Oblique 400,
Bold Oblique 700. Declared in `src/brand.css`; downloaded only when the
preference is selected. Keep `LICENSE` with these files.
