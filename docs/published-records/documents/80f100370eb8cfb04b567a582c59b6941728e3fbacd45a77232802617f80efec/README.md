# S2 browser QA — Finance → Documents (2026-10-01)

Environment: Chromium (Claude in Chrome), the **production build** (`vite build` + `vite preview` on
`127.0.0.1:4173`, proxy → API on `127.0.0.1:8031`), real API (`uvicorn --factory app.main:create_app`) on the
disposable **`lifeos_test`** database, `LIFEOS_DOCUMENTS_ENABLED=true` with an **ephemeral synthetic keyring**
generated by `python -m app.cli keyring-generate` in the session scratchpad (0600, outside the repository; never
committed), file mail adapter (no real mail). Accounts: `qa-docs-owner@example.com` (bootstrap owner),
`qa-docs-member@example.com` (inserted). Files: synthetic only — pypdf-generated PDFs, a generated PNG, the
`sips`-converted synthetic JPEG fixture, a pypdf AES-256 password-protected PDF, an HTML file named `.png`, a 16 MiB
padded file. No owner document was used.
