# Handoff: панель «Прояснить» (Clarify) — Life OS

## Overview

Панель-поповер шага **«Прояснить»** методики GTD. Пользователь тапает по «сырой» заметке
во Входящих — панель открывается и спрашивает один вопрос: **что это за пункт?**
Пользователь выбирает один из шести исходов, пункт уходит из Входящих в соответствующее
место системы, панель закрывается.

Ширина панели — **680px** (примерно с карточку контента). Спроектированы **три раскладки**
блока действий (на выбор) и **две темы** для каждой.

---

## About the Design Files

Файлы в этом архиве — **дизайн-референс, сделанный в HTML**. Это прототип, показывающий
задуманный внешний вид и поведение, **а не продакшн-код для копирования**.

Задача разработчика — **воспроизвести эти макеты в существующем окружении целевого
проекта** (React, Vue, SwiftUI, native и т.д.), используя его сложившиеся паттерны и
библиотеки. Если окружения ещё нет — выбрать подходящий фреймворк и реализовать макеты в нём.

Разметка в прототипе написана инлайновыми стилями (требование среды прототипирования).
**Не переносите инлайновые стили в продакшн** — переведите их в принятый в проекте способ
(CSS-модули, styled-components, Tailwind-конфиг на этих токенах и т.п.). Значения токенов
ниже — источник истины.

## Fidelity

**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и копирайт.
UI следует воспроизводить точно, но **на компонентах и утилитах целевой кодовой базы**.

Всё построено на дизайн-системе **Life OS** (тёмная тема по умолчанию, тёплый акцент
только «на ставках»). Дизайн-система приложена в `_ds/` — при реализации подключайте
**существующую** систему проекта, а не копию отсюда.

### Раскладка 1a — пилюли, компактный кластер

Самая низкая по высоте. Подходит, если панель должна занимать минимум вертикали.

> **Геометрия — важно.** Это **не один ряд.** При ширине панели `680px` контентная
> область — `635px`, а шесть пилюль в сумме занимают `816px` (+ `5×8px` гаттеров).
> Кластер закономерно **переносится в 2 ряда**: `сделать сейчас / делегировать /
> отложить / в проект` в первом, `в справочник / удалить` во втором.
> Перенос — штатное поведение, не баг вёрстки. Не пытайтесь ужать его в одну строку:
> при русских подписях это требует убрать иконки у всех второстепенных пилюль **и**
> опустить кегль до `12px`, что ломает стиль капсул системы.
> Если одна строка принципиальна — нужны более короткие подписи, а не более мелкий шрифт.

- измеренные ширины пилюль (Work Sans, тема dark): `159 / 143 / 115 / 111 / 142 / 106` px
- каждая пилюля: высота `38px`, радиус `999px`, `white-space: nowrap`, иконка `15px` + подпись `13px`, `gap: 8px`

## Interactions & Behavior

**Открытие.** Панель появляется по тапу на строку во Входящих. Как модальный поповер:
подложка `var(--modal-backdrop)`, панель по центру или закреплена у исходной строки.
Появление — `260ms` (`--dur-slow`), фейд + сдвиг на несколько пикселей вверх. Без bounce и spring.

**Закрытие.** Крестик в шапке, клавиша `Esc`, клик по подложке. Закрытие — `180ms`.

**Выбор исхода (действия 1–5).** Один тап = применение исхода, панель закрывается,
пункт покидает Входящие. Показать системный тост в голосе системы (сухо, строчными),
например `отложено · вернём во входящие в пн`. Тост — нейтральная поверхность,
не оранжевая (оранжевый аватар только у тостов телеграм-бота).

**Удаление.** Двухшаговое (см. выше). Состояние подтверждения живёт внутри панели;
панель не закрывается между шагами. После `удалить навсегда` — закрыть панель и показать
тост с возможностью отмены, если в проекте есть undo.

**Клавиатура (рекомендация).** Цифры `1`–`6` выбирают исход, `Esc` закрывает.
В состоянии подтверждения `Esc` сначала отменяет подтверждение, второй `Esc` закрывает панель.
Фокус при открытии — на первое действие. Фокус-кольцо — 2px `var(--orange-focus-ring)`
для акцентных элементов, синее кольцо для остальных.

**Анимации.** Раскрытие блока подтверждения — `180ms`, `cubic-bezier(0.22, 1, 0.36, 1)`,
высота + прозрачность. Все hover-переходы — `140ms` тем же изингом.
Hover-сдвиги — только `translateY`, без `scale`.

**Адаптивность.** Ниже ~720px ширины: панель на всю ширину минус `16px` гуттеры,
сетка 1b схлопывается в 2 колонки, затем в 1. Раскладка 1c работает на мобильном как есть —
высота строки `54px` уже выше минимума в 44px.

**Пустые/краевые случаи.** Длинный заголовок заметки переносится (не обрезается),
панель растёт по высоте. Если заголовок длиннее ~3 строк — обрезать по 3 строкам с многоточием.

## State Management

Состояние панели минимально:

| Переменная | Тип | Назначение |
|---|---|---|
| `isOpen` | boolean | открыта ли панель |
| `item` | объект заметки | `{ id, title, capturedAt }` — источник заголовка и меты |
| `confirmingDelete` | boolean | раскрыт ли блок подтверждения (только 1c) |

Переходы:
- тап по заметке во Входящих → `isOpen = true`, `item = <заметка>`, `confirmingDelete = false`
- тап по действию 1–5 → вызов мутации исхода → `isOpen = false`
- тап по «удалить» → `confirmingDelete = true`
- «отмена» → `confirmingDelete = false`
- «удалить навсегда» → мутация удаления → `isOpen = false`
- закрытие панели любым способом → сброс `confirmingDelete = false`

**Данные.** Панель читает уже загруженную заметку — своей загрузки не требует.
На запись нужны шесть мутаций (выполнить/делегировать/отложить/в проект/в справочник/удалить).
Оптимистичное обновление списка Входящих с откатом по ошибке.

### Прочее

- Радиусы: `8px` (плашка иконки 1c), `9px` (плашка 1b), `10px` (хинт), `12px` (список, карточка 1b, блок подтверждения), `16px` (панель), `999px` (пилюли, кнопки подтверждения)
- Отступы (4pt): использованы `8 / 10 / 11 / 12 / 13 / 14 / 16 / 18 / 20 / 22`
- Изинг: `--ease` = `cubic-bezier(0.22, 1, 0.36, 1)`; длительности `140ms` hover, `180ms` default, `260ms` открытие

## Assets

- **Иконки — Lucide**, обводка 1.5–1.7px, без заливок. Использованы:
  `zap` (сделать сейчас), `user` (делегировать), `clock` (отложить), `briefcase` (в проект),
  `book-open` (в справочник), `trash-2` (удалить), `x` (закрыть),
  `chevron-right` (шеврон строки), `alert-triangle` (подтверждение).
  В прототипе они заинлайнены как SVG — в проекте берите их из установленной библиотеки иконок.
- **Шрифты** — Onest, Work Sans, JetBrains Mono, все три с кириллицей, грузятся с Google Fonts
  через `colors_and_type.css` дизайн-системы. Отдельных файлов шрифтов в архиве нет.
- Изображений и иллюстраций в дизайне нет — Life OS их не использует.
