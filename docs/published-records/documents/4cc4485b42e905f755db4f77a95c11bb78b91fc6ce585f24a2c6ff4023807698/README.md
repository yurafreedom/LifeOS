# DejaVu Sans for JENKIN

Official DejaVu 2.37 package downloaded from:
https://downloads.sourceforge.net/project/dejavu/dejavu/2.37/dejavu-fonts-ttf-2.37.zip
SHA256 verified against the official download page:
7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a

Includes original Regular, Bold, Oblique, Bold Oblique TTFs plus locally converted full WOFF files and fonts.css. Russian alphabet and Ukrainian І Ї Є Ґ upper/lower-case checked in all four font cmap tables. No subsetting performed.

Install TTFs on Mac via Font Book. For the web, place fonts.css beside WOFF files, import it, and set typography font-family to 'DejaVu Sans', sans-serif. Preserve LICENSE when distributing.

The logo sheet labels use Regular 400. The Editorial logo is separate outlined Latin Modern lettering.
