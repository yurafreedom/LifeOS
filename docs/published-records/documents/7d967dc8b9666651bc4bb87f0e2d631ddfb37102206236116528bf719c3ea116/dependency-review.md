Global GitHub database dates above may differ from the original maintainer advisory's publication date. The raw metadata preserves which date was retrieved. No withdrawn advisory was returned. Python advisory query matched only pip in this installed environment; this is not proof that all other libraries are vulnerability-free. Node scanner reports five vulnerable package entries (3 moderate, 2 high); multiple advisories on brace-expansion and the shared Vitest root cause must not be counted as five independent application defects.

App runtime/parser/crypto packages include FastAPI 0.139.2, Starlette 1.3.1, cryptography 50.0.2, pypdf 6.19.0, SQLAlchemy 2.0.51 and psycopg 3.3.4. Their exact inventory is retained, not inferred from version ranges. Npm's listed matches are dev dependencies; the built client has React/ReactDOM as its direct runtime dependency family. Full transitive data-flow reachability and malicious build-input scenarios remain unassessed. No external scanner received repository source, logs, keys or documents; only public dependency identities were queried. No lockfiles or dependencies were updated.

Install/build scripts: ordinary `npm ci` and repository build/test commands ran in the isolated checkout. `hasInstallScript` flags and platform-optional installed/missing packages are recorded. These executions trust the pinned supply chain; this audit did not provide an OS sandbox proof for every install script. Third-party Google Fonts requests are present in index.html; the browser harness intercepted and aborted them. Source maps were built and checked by narrow secret recognizers; maps expose source and are not inherently secret leakage.
